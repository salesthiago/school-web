# Fonte Satoshi

O `tokens.css` espera o arquivo **`Satoshi-Variable.woff2`** nesta pasta.

Ele não vem no pacote porque a licença (ITF Free Font License, texto em
`LICENSE-Satoshi-FFL.txt`) proíbe redistribuir o arquivo. Baixar é grátis:

1. <https://www.fontshare.com/fonts/satoshi> → **Download family**
2. Do zip, copie `Satoshi_Complete/Fonts/WEB/fonts/Satoshi-Variable.woff2` para esta pasta.
3. Não renomeie, não converta, não faça subset (a licença proíbe modificar).

A licença permite usar a fonte em sites e aplicativos **próprios** (self-host
via `@font-face`, apps mobile/desktop). Não permite oferecer a fonte para
terceiros usarem nos conteúdos deles (ex.: seletor de fonte num editor).

Sem o arquivo, a interface cai para Inter / fonte do sistema — funciona, mas
não é o visual aprovado.
